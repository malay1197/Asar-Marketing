## File Structure
- `index.html`: Complete semantic HTML5 structure featuring all 24 required sections, Schema.org structured data, open graph tags, and responsive layouts.
- `styles.css`: Custom CSS styling for luxury typography, scrollbar, scroll reveals, card hover states, and warm ivory/gold palette.
- `script.js`: Interactive functionality including sticky header, mobile menu drawer, category filter tabs, interactive founder photo uploader, contact form handler, and direct WhatsApp message generator.

---

## How to Run Locally

### Option 1: Direct File Opening
Simply open `index.html` in any web browser (Chrome, Edge, Safari, Firefox).

### Option 2: Local Server (Node / Python)
```bash
# Using Python:
python -m http.server 3000

# Or using Node npx:
npx serve
```
Then navigate to `http://localhost:3000`.
